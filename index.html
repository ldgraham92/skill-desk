What runs locally?

Skill-Desk is a desktop app for Windows, macOS and Linux. Its bundled local service watches ~/.agents/skills, ~/.codex/skills and ~/.claude/skills, including configured CLI homes. No separate Python installation is needed.

Choose All, Codex or Claude in the library. Skills show which provider they belong to, and you can preview a copy for the other provider. Use $skill-name in Codex and /skill-name in Claude Code. The authoring CLI does not change the prompt target.

Signed updates install from the app's Updates window. Your skills stay on your computer. Linux in-app updates require the AppImage build.
