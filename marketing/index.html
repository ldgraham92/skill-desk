What runs locally?

The actual app runs a Python server on your Mac. Start with a signed-in Codex or Claude Code CLI and PyYAML installed. Its default library is ~/.agents/skills. To use a Claude library:

python3 scripts/skill_desk.py \
  --provider claude --library claude

This selects ~/.claude/skills. Existing libraries are not moved or duplicated. Imported skills may contain agent-specific instructions; inspect them before use. This file is a demonstration, not the installer.
